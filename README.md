# d-frame
An iframe wrapper for powerful web app integrations.

Lightweight, vanilla JS, no dependency.

The optional Vue adapters (`lib/vue`, `lib/vue-reactive`, `lib/vue-router`) require vue >= 3.3 (>= 3.4.28 for types) and vue-router >= 4 for types. They are not declared as peer dependencies so that the core stays installable alongside any Vue version.

Supports:
  - dynamic resizing
  - navigation syncing
  - notification passing

See [the documentation](https://data-fair.github.io/frame/latest/).
